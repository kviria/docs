Kviria is location infrastructure for AI to search and reason over places across the United States. It resolves natural-language location requests (*"a cafe across from the bank"*, *"espresso in Williamsburg, Brooklyn"*, *"597 Greene Ave, Brooklyn"*), profiles and compares street-level neighborhood conditions, and sequences multi-stop walking itineraries or fair meeting points.

Every endpoint and MCP tool returns structured JSON facts only; your agent speaks the reply.

## Three tools, one contract

| Tool / Endpoint | Use it when | Credits |
|---|---|---|
| `kviria` · [`POST /v1/agent`](/api/agent) | Finding a place, address, or intersection; answering nearby, across-the-street, next-to, or multi-turn follow-ups | `1` credit |
| `kviria_profile` · [`POST /v1/profile`](/api/profile) | Auditing street frontage, arterial proximity, building context, walkable amenities, and claims across `1` to `5` US locations | `1` credit per location (`1`–`5`) |
| `kviria_batch` · [`POST /v1/batch`](/api/batch) | Grounding a list of `2` to `15` stops, clustering and ordering a walking itinerary, or finding a fair meeting hub for `2` to `5` people | `1` credit per `3` items (`1`–`5`) |

## How a multi-turn conversation works

Every `/v1/agent` (`kviria`) call sends `request` (`"ask"` with the user's message in `words`, or structured fields) plus the signed `state` from the previous response.

<Steps>
  <Step title="Turn 1: Ask">
    User says: *"a cafe in Williamsburg, Brooklyn"*

    ```json Request
    {
      "request": "ask",
      "words": "a cafe in Williamsburg, Brooklyn",
      "state": ""
    }
    ```

    Kviria returns `decision: "many"` with matching places, `distinguishBy: "street"`, and a signed `state`.
  </Step>
  <Step title="Turn 2: Pick">
    User says: *"the first one"*

    ```json Request
    {
      "request": "ask",
      "words": "the first one",
      "state": "<STATE_1>"
    }
    ```

    Kviria returns `decision: "one"` with `Devocion`, `69 Grand St`, its coordinate `{ lat, lng }`, and a new `state`.
  </Step>
  <Step title="Turn 3: Follow up">
    User says: *"what is across the street from it?"*

    ```json Request
    {
      "request": "ask",
      "words": "what is across the street from it?",
      "state": "<STATE_2>"
    }
    ```

    Kviria uses the settled place carried in `state` and returns the places across Grand St.
  </Step>
</Steps>

## Five decisions (`/v1/agent`)

Every `/v1/agent` turn returns one `decision` and a new `state`:

| Decision | Meaning | Your agent's move |
|---|---|---|
| `one` | The place is settled | State the name, distance, and facts from `target` |
| `one_unconfirmed` | Partial name match (location held until confirmed) | Ask the user to confirm the place (`yes` or `no`) |
| `many` | Multiple places match | Ask which one using `distinguishBy` (at most 3 options) |
| `unclear` | Needs clarification, a heading, or an area choice (`areaOptions`) | Ask the question or offer the 3 `areaOptions` |
| `none` | Nothing matched in the map data | Tell the user what could not be found and ask for another detail |
