<Steps>
  <Step title="Connect or get a key">
    <Tabs>
      <Tab title="MCP (One-click OAuth)">
        No key or password is required for OAuth MCP clients. Add `https://api.kviria.com/mcp` and click **Allow** on the connect page to expose `kviria`, `kviria_profile`, and `kviria_batch`, or paste `Read https://kviria.com/setup.md to connect Kviria (voice, web, MCP, or HTTP) to my agent or project.` into your AI assistant. See [For agents](/agents) and [MCP server](/api/mcp).
      </Tab>
      <Tab title="HTTP API (Key)">
        Open [api.kviria.com/key](https://api.kviria.com/key) and click **Create a key**. Copy the `kvr_...` key (shown once).

        Every account includes `600` free credits per day (`1` credit for `/v1/agent`, `1` to `5` credits for `/v1/profile` and `/v1/batch`) and `60` requests per minute. See [Rate limits and errors](/api/limits).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Send Turn 1 (area search without a GPS pin)">
    Send the user's message with `request: "ask"` and `words`. Save the returned `state` for the next turn.

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://api.kviria.com/v1/agent" \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer $KVIRIA_KEY" \
      -d '{
        "request": "ask",
        "words": "a cafe in Williamsburg, Brooklyn",
        "state": ""
      }'
    ```

    ```typescript TypeScript
    async function askKviria(
      words: string,
      state = "",
      anchor?: { lat: number; lng: number },
    ) {
      const res = await fetch("https://api.kviria.com/v1/agent", {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          Authorization: `Bearer ${process.env.KVIRIA_KEY}`,
        },
        body: JSON.stringify({
          request: "ask",
          words,
          state,
          ...(anchor ? { anchor } : {}),
        }),
      });
      return res.json();
    }
    ```

    ```python Python
    import os
    import requests

    def ask_kviria(words: str, state: str = "", anchor: dict | None = None) -> dict:
        body = {"request": "ask", "words": words, "state": state}
        if anchor is not None:
            body["anchor"] = anchor
        res = requests.post(
            "https://api.kviria.com/v1/agent",
            headers={"Authorization": f"Bearer {os.environ['KVIRIA_KEY']}"},
            json=body,
            timeout=20,
        )
        return res.json()
    ```

  <Step title="Send Turn 2 (pick an option using state)">
    Pass the user's answer back with the returned `state`:

    ```bash cURL
    curl -X POST "https://api.kviria.com/v1/agent" \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer $KVIRIA_KEY" \
      -d '{
        "request": "ask",
        "words": "the first one",
        "state": "AXbU2v9QmZ3k8sJt0LrE4wHn7cYq1pKf6gNa5oTd"
      }'
    ```

    Trimmed response (`decision: "one"`):

    ```json Response
    {
      "decision": "one",
      "target": {
        "gers": "08f2a100d8cb5d1a0390a5e1b5c6d701",
        "name": "Devocion",

        "confidence": 0.96,
        "location": { "lat": 40.71602, "lng": -73.96134 },

      ],
    ```

    <Note>
      When you already have the user's GPS coordinate, include `"anchor": { "lat": 37.76326, "lng": -122.4152 }` on the first turn instead of an area name, and omit `anchor` on follow-up turns unless the user moves.
    </Note>
  </Step>

  <Step title="Profile locations or sequence multi-stop visits">
    - Use [`POST /v1/profile`](/api/profile) (`kviria_profile`) to audit street class, arterial distance, building context, walking amenities, and location claims across `1` to `5` US places in one call.
    - Use [`POST /v1/batch`](/api/batch) (`kviria_batch`) to ground a list of `2` to `15` stops, order a walking itinerary, or compute a fair meeting point for `2` to `5` people.
    - Load the agent system prompt from [kviria.com/skill.md](https://kviria.com/skill.md) and schemas from [api.kviria.com/openapi.json](https://api.kviria.com/openapi.json).
  </Step>
</Steps>
