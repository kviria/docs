---
title: Profile endpoint
description: Street-level neighborhood dossiers, claim checks, and side-by-side comparisons for 1 to 5 US locations.
icon: map-pin
---

```text Endpoint
POST https://api.kviria.com/v1/profile
Authorization: Bearer kvr_...
Content-Type: application/json
Max body: 16 KB
MCP tool: kviria_profile
```

`POST /v1/profile` (exposed over MCP as `kviria_profile`) returns street-level physical facts for `1` to `5` US locations in parallel, plus a fact-first `compare` summary when `2` or more locations resolve.

Every call charges `1` credit per requested location (`1` to `5` credits). See [Rate limits and errors](/api/limits).

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `locations` | array (`1`–`5`) | Yes | Locations to profile. Each item accepts optional `label` (`<= 80` chars) and **exactly one** of `anchor` (`{ lat, lng }`), `address` (`{ number, street }` + optional `area`), or `place` (`{ name }` + optional `area`). Do not combine `anchor` with `area`. |
| `radiusM` | `250 \| 500` | No | Amenity scan radius in meters (default `500`; sparse areas may expand automatically). |
| `domains` | string[] | No | Subset of amenity domains to scan (defaults to all `9`): `grocery`, `cafe`, `restaurant`, `bar`, `park`, `pharmacy`, `fitness`, `school`, `transit`. |
| `claims` | object | No | Optional physical claim checks evaluated per location: `quietStreet` (`boolean`) and `maxWalkM` (map of domain -> threshold meters, `50`–`2000`). Any domain named in `maxWalkM` is automatically included in `domains`. |

## Example: checking a "quiet street" claim

```bash cURL
curl -X POST "https://api.kviria.com/v1/profile" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $KVIRIA_KEY" \
  -d '{
    "locations": [
      {
        "label": "Hotel San Jose",
        "address": { "number": "1316", "street": "South Congress Ave" },
        "area": "Austin, TX"
      },
      {
        "label": "Mission House",
        "address": { "number": "2128", "street": "Folsom St" },
        "area": "San Francisco, CA"
      }
    ],
    "radiusM": 500,
    "domains": ["cafe", "grocery", "park", "transit"],
    "claims": {
      "quietStreet": true,
      "maxWalkM": { "cafe": 300, "grocery": 500 }
    }
  }'
```

## Response fields

| Field | Description |
|---|---|
| `locations[]` | One result per input in order. `status` is `"ok"`, or `"ambiguous"` / `"not_found"` / `"out_of_coverage"` with a `reason` string (and up to `3` `candidates` when ambiguous). |
| `street` | Frontage street `name`, road `class`, perpendicular `distanceM`, `isArterial` (`motorway`, `trunk`, `primary`, `secondary`), `nearestArterial`, and `cornerDistanceM`. |
| `block` | `250` m block statistics (`doors`, `buildings`, `crossingsCount500m`). `residentialShare` and building height percentiles return `null` when local sample size is too small. |
| `amenities` | Per requested domain: `count250m`, `count500m`, and `nearest` place with straight-line `distanceM` and street-network `walkM`. The `transit` domain uses US National Transit Map stops (`source: "ntad_transit"`, categorized as `subway_station`, `rail_station`, `light_rail_station`, `ferry_terminal`, `bus_stop`, or `transit_stop`) and falls back to map POI matches (`source: "overture_pois"`) when no transit feed covers the area. |
| `demographics` | Optional block-group neighborhood demographics derived from U.S. Census Bureau ACS 5-Year (`2020-2024`) estimates (`source: "us_census_acs5"`): `geoid`, `vintage`, `population`, `populationDensityPerKm2`, `medianHouseholdIncomeUsd`, `medianGrossRentUsd`, `renterShare`, `medianYearBuilt`, `medianAge`, and `commute` shares (`carShare`, `transitShare`, `walkShare`, `bikeShare`, `workFromHomeShare`). Individual metrics return `null` when Census suppresses the estimate or local sample counts are small; omitted over unmapped water or outside Census block groups. |
| `terrain` | Optional bare-earth topography derived from U.S. Geological Survey (USGS) 3DEP elevation data (`source: "usgs_terrarium_dem"`): `elevationM` (whole meters above sea level), `slopePct` (local ground grade in percent), and `relief250mM` (elevation range in meters within `250` m). Omitted over open water or unmapped areas. |
| `claimsCheck` | Present when `claims` was sent. Each verdict is `"supported"`, `"contradicted"`, or `"insufficient_data"` alongside the exact `measured` values. `quietStreet` evaluates frontage street class and proximity to the nearest arterial road. |
| `compare` | Present when `2` or more locations resolve: fact-first winners for `quietestStreet`, `farthestFromArterial`, `mostAmenities500m`, `highestResidentialShare`, `lowestMedianHeightM`, `closestByDomain`, plus optional `highestMedianIncomeUsd`, `lowestMedianRentUsd`, `highestTransitCommuteShare`, `flattestLocation`, and `highestElevationM` whenever `2` or more resolved locations carry the underlying data. |

<Note>
  **Ambiguity handling:** If a named place matches multiple locations or an area name is ambiguous, that entry returns `status: "ambiguous"` with up to `3` `candidates` (name, detail, and location) instead of guessing, while other locations in the same call still resolve normally.
</Note>
